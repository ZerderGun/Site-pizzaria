FORNO NOBRE — SITE DEMONSTRATIVO

COMO ABRIR
1. Extraia todos os arquivos para a mesma pasta.
2. Abra index.html em um navegador atualizado.
3. É necessária conexão com a internet para carregar as fontes e imagens externas.

ANTES DE PUBLICAR
1. Abra script.js.
2. Substitua WHATSAPP_NUMBER pelo número real da pizzaria, com código do país e DDD, somente números. Exemplo de formato: 5521999999999.
3. Atualize nomes, descrições, preços e imagens no array `pizzas` para refletir o cardápio real.
4. Atualize textos, telefone, endereço, horários e redes sociais conforme os dados verdadeiros do estabelecimento.
5. Publique os arquivos em um serviço de hospedagem estática (por exemplo, GitHub Pages, Netlify ou Vercel).

LIMITAÇÕES
- O carrinho funciona no navegador, mas não salva pedidos em um banco de dados.
- O botão do WhatsApp monta uma mensagem e abre o WhatsApp; a pessoa ainda precisa enviar a mensagem.
- Este projeto não processa pagamentos nem confirma pedidos automaticamente.
- Os preços e sabores são demonstrativos, não foram confirmados pela pizzaria.
